# FARX GOD — FARX Studio Android Preview

An Android Studio shell and a small executable slice of the independent FARX language.

**Current deliverable:** Android editor + console, preview interpreter, unit tests, GitHub Actions workflow that tests and builds `FARX-Studio-Android.apk`.

**Important:** This is a foundation, not the finished 150+ mode language ecosystem. See [Persian build guide](docs/README-FA.md), [language spec](docs/LANGUAGE-SPEC.md), [mode roadmap](docs/MODE-ROADMAP.md), and [architecture](docs/ARCHITECTURE.md).

## Quick start
1. Open this repository in GitHub.
2. Push the project files to the root of `main`.
3. Open Actions → FARX GOD - Android APK → Run workflow.
4. Download the `FARX-Studio-Android` artifact.

The workflow also runs unit tests before producing the APK.
